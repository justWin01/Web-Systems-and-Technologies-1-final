# E-Commerce Website (HTML, CSS, JavaScript)

This project is a simple front-end e-commerce website built with HTML, CSS, and JavaScript. It includes essential pages such as Home, Products, Cart, Contact, and About, providing users with a smooth browsing experience. The layout is designed to be clean and user-friendly, giving visitors an easy way to navigate through the different sections of the site.

The structure of the project consists of organized folders for CSS, JavaScript, and images. Each HTML page has a dedicated stylesheet to ensure consistent styling throughout the website, such as `main.css` for global layouts, `products.css` for the product page, `cart.css` for the shopping cart, and `contact&about.css` for informational pages. JavaScript files like `products.js` and `cart.js` power the dynamic behavior and interactivity of the product list and cart system.

Users can view products, add items to their cart, and review the items they selected through the cart page. The website uses localStorage to temporarily store cart data, allowing the cart to retain items even if the page is refreshed. Additional features such as quantity updates and item removal help create a simple but functional shopping experience.

This project runs entirely on the front end, making it easy to set up—simply open `index.html` in any browser to start. It serves as a foundation for more advanced development, where backend integration, database storage, and authentication features can be added in the future to enhance its functionality.
